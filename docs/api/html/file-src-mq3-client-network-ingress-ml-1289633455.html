# clientPacket

function clientPacket(runtime, address, data)

Wraps a UDP datagram in message storage, runs client packet processing, and records its result and packet count. Reuses the runtime Huffman codec and advertises reassembly capacity including the four-byte sequence prefix. Missing input returns error 6994; datagrams beyond `MAX_MSGLEN` return error 7981 before packet accounting. Otherwise returns the packet-event result and retains it in `lastPacketResult`.

ParameterTypeDefaultDescription
runtimedynamic—Mutable network ingress record/storage; this routine assigns `runtime.codec`, `runtime.lastPacketResult`, `runtime.packetCount`.
addressdynamic—Source network address checked by the client packet-event path.
datadynamic—Received UDP datagram bytes, wrapped in message storage large enough for netchan reassembly.

# create

function create(connectionState, netchanRuntime, protocol, hostServices)

Connect client packet handling, netchan decoding, and protocol parsing to one ingress runtime. Creates packet-event state and binds its callbacks to this runtime. All four arguments must be present, and the supplied Services must contain a connectionless service bundle; missing configuration returns error 6994.

# parse

function parse(packetHost, state, msg)

Parse a server payload and synchronize snapshot sequencing and reliable server-command history. The packet-event server sequence is copied into the snapshot parser before decoding. Afterwards the decoded server-command ring is shared with the outgoing netchan XOR encoder. Returns and retains the parser result in `lastParseResult`.

ParameterTypeDefaultDescription
packetHostdynamic—Packet-event Services record whose context references this ingress runtime.
statedynamic—Packet-event State containing the physical server-message sequence number.
msgdynamic—Mutable message positioned at the server payload after netchan processing.
