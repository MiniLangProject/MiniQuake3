# updateBattleInventory

function updateBattleInventory(services, bot, enemy)

Set `bot.inventory[ENEMY_HEIGHT]` to `n.trunc32(dz)` and `bot.inventory[ENEMY_HORIZONTAL_DIST]` to `n.trunc32(n.fsqrt(n.fadd(n.fmul(dx,dx),n.fmul(dy,dy))))` in `mq3.game.bot_inventory_ai.updateBattleInventory`.

ParameterTypeDefaultDescription
servicesdynamic—Host service callbacks; accesses `entityInfoFn`.
botdynamic—Bot AI state; accesses `origin` and `inventory`. May update `bot.inventory[ENEMY_HEIGHT]` and `bot.inventory[ENEMY_HORIZONTAL_DIST]` in place.
enemydynamic—Value passed as argument 2 to `services.entityInfoFn`.
