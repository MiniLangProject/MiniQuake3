# decodePixels

extern function decodePixels(input as bytes, inputBytes as i32, offset as i32, width as i32, height as i32, pixelBytes as i32, rle as i32, output as bytes, outputBytes as i32) from "playable_window.dll" symbol "playable_decode_tga_pixels" returns i32

Decodes bounded TGA pixel packets into RGBA output, including RLE and orientation handling.

ParameterTypeDefaultDescription
inputbytes—Read-only encoded TGA image bytes.
inputBytesi32—Encoded input-buffer length in bytes.
offseti32—Byte offset where TGA pixel data begins.
widthi32—Width of the image, surface, or viewport in pixels.
heighti32—Height of the image, surface, or viewport in pixels.
pixelBytesi32—Bytes per encoded source pixel.
rlei32—Nonzero selects TGA run-length packet decoding.
outputbytes—Writable RGBA8 pixel buffer.
outputBytesi32—Capacity of the native output buffer in bytes.

Returns: 1 on success; negative codes identify invalid bounds, unsupported pixels, output overflow, or truncated packets.
