# traceThroughBrush

function traceThroughBrush(trace, planes, contents, start, finish, mins, maxs, capsule, radius, capsuleOffset)

Sweep a box or capsule against a convex brush, updating and returning the existing trace. A nearer entering hit replaces the fraction, contents, and impact plane. Starting inside sets startsolid; remaining inside also sets allsolid and a zero fraction. Starting inside but exiting does not replace the hit fraction. Empty brushes and separating planes leave the trace unchanged.

ParameterTypeDefaultDescription
tracedynamic—Accumulated nearest-hit result, mutated in place; its fraction limits new entering hits.
planesdynamic—Brush boundary Plane records with outward unit normals in the sweep coordinate system.
contentsdynamic—Brush contents bitmask reported on an entering hit or an allsolid result.
startdynamic—Three-component sweep start position in world units.
finishdynamic—Three-component sweep end position in the same coordinate system.
minsdynamic—Box minimum corner relative to the moving origin; used only when capsule is false.
maxsdynamic—Box maximum corner relative to the moving origin; used only when capsule is false.
capsuledynamic—True selects capsule support; false selects axis-aligned box support.
radiusdynamic—Capsule end-sphere radius in world units; used only for capsule sweeps.
capsuleOffsetdynamic—Vector from the capsule center to one end-sphere center; used only for capsule sweeps.
