# addSharedLoop

function addSharedLoop(state, id, key, origin, sound, volume, globalSound)

Register an enabled looping source at cursor zero and return its zero-based source index. Copies the origin vector but retains the supplied sound record. Rejects duplicate identifiers, invalid PCM/gain, or registrations beyond MAX_SOURCES with error 7620.

ParameterTypeDefaultDescription
statedynamic—Mixer whose sources collection is extended in place.
iddynamic—Caller identifier, unique among sources currently registered in this mixer.
keydynamic—String used to group sources only when sound and playback cursor also compare equal.
origindynamic—Three-component source position in world units; copied into the source.
sounddynamic—Decoded WAVE Sound containing at least one complete sample frame; retained without copying PCM.
volumedynamic—Linear source gain from zero through one before distance attenuation and stereo panning.
globalSounddynamic—True gives both output channels the full source gain, bypassing spatial attenuation and panning.

# render

function render(state, listener, right)

Mix one stereo PCM chunk, advancing only enabled sources with a positive spatial gain. Matching key, sound, and cursor values share resampling work. Source PCM is downmixed to mono before panning; fractional source positions select the preceding frame. A single chunk-wide limiter scales peaks above 32767 before signed 16-bit output conversion. Disabled and fully attenuated sources keep their cursors. Returns a Chunk or error 7620 for invalid listener data.

ParameterTypeDefaultDescription
statedynamic—Mixer supplying chunkFrames and outputRate; audible source cursors are updated in place.
listenerdynamic—Three-component listener position in world units.
rightdynamic—Listener's right vector; its length must lie from 0.99 through 1.01.

# spatialize

function spatialize(origin, listener, right, volume, globalSound)

Compute stereo gains using linear distance attenuation and the listener's right-axis projection. Local sources have full distance gain through SOUND_FULLVOLUME world units; panning divides that gain between left and right. Global sources receive the full volume in both channels, with reported distance zero and attenuation one. A nonpositive volume returns zero gains, distance, and attenuation.

ParameterTypeDefaultDescription
origindynamic—Source XYZ position in world units.
listenerdynamic—Listener XYZ position in the same coordinate system.
rightdynamic—Listener's normalized three-component right vector; positive projection favors the right channel.
volumedynamic—Linear source gain before attenuation and panning.
globalSounddynamic—Whether to bypass positional attenuation and panning.
